# Doton v2

Соревновательная игра «соедини точки»: онлайн-дуэли, в которых побеждает скилл.
Мир игры — «Цепь»: поле — плата, цепочка — ток, кольцо — короткое замыкание.
Концепция: [CONCEPT.md](CONCEPT.md). История поиска визуала: `docs/design-*.html`.

## Структура

| Пакет | Что это |
|---|---|
| `packages/core` | Правила игры: поле, цепочки, кольца, очки, детерминированный RNG. Чистые функции без зависимостей, общие для клиента и сервера. |
| `apps/client` | Клиент: Vite + TypeScript, Canvas-рендер поля, темы «Чертёж»/«Графит». |

## Команды

```bash
pnpm install
pnpm dev        # клиент на http://localhost:5173
pnpm test       # тесты ядра (vitest)
pnpm typecheck  # проверка типов во всех пакетах
pnpm build      # сборка
```
