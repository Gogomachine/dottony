# dotoscope

Соревновательная игра «соедини точки»: онлайн-дуэли, в которых побеждает скилл.

**ROUND THINGS INC** выпускает **dotoscope** — прибор для наблюдения за круглыми
объектами. Игрок кладёт образец, ведёт наблюдение, копит вспышки и снимает
потенциал. Маскота нет: лицо игры — сам прибор.
(Имена по порядку: Doton → Zaapo! → dotoscope. Репозиторий, внутренние пакеты и
сервис на Render хранят прежние имена — переименовывать их дороже, чем терпеть.)
Концепция: [CONCEPT.md](CONCEPT.md). История поиска визуала: `docs/design-*.html`.

Играть: https://gogomachine.github.io/dottony/

## Структура

| Пакет | Что это |
|---|---|
| `packages/core` | Правила игры: поле, цепочки, резонанс с заявкой на цвет, вспышки с каскадом увеличения, детерминированный RNG. Чистые функции без зависимостей, общие для клиента и сервера. |
| `packages/protocol` | Контракт клиент ↔ сервер: zod-схемы запросов и типы ответов. |
| `apps/client` | Клиент: Vite + TypeScript, Canvas-рендер, темы «Чертёж»/«Графит», Telegram Mini App. |
| `apps/server` | Сервер: Fastify + libSQL. Дуэли по WebSocket с проверкой каждого хода через ядро, рекорды цепочек и тапа (переигрываются по журналу ходов), таблицы, вход через Telegram / гостём. |

## Команды

```bash
pnpm install
pnpm dev                        # клиент на http://localhost:5173
pnpm --filter @doton/server dev # сервер на http://localhost:3000
pnpm test                       # тесты ядра и сервера (vitest)
pnpm typecheck                  # проверка типов во всех пакетах
pnpm build                      # сборка
```

Локальная игра с сервером: запусти сервер и собери клиент с
`VITE_API_URL=http://localhost:3000 pnpm dev`.

## Деплой

- **Клиент** публикуется на GitHub Pages автоматически при каждом пуше
  (`.github/workflows/deploy.yml`). Адрес API задаётся переменной
  репозитория `DOTON_API_URL` (Settings → Secrets and variables →
  Actions → Variables); без неё клиент работает в оффлайн-режиме.
- **Сервер** — `render.yaml` для Render (Blueprint, free-план). Секрет
  `JWT_SECRET` генерируется сам — но при переезде на другой сервис его
  переносят вручную: этим ключом подписаны токены игроков, а токен в
  браузере — единственный ключ к гостевому аккаунту.
- **Боевой сервер и база** — [docs/DEPLOY.md](docs/DEPLOY.md): платный
  план, Turso, регион, переменные окружения, порядок переезда.
- **Турнир дня** идёт с 9:00 до 22:00 по Москве, итоги в 23:00: один сид на
  всех, взнос 1000 жетонов, три захода в зачёт по сумме, котёл делится между
  сыгравшими. Правила и доли — в [CONCEPT.md](CONCEPT.md), время задаётся
  константами в `packages/core/src/tourney.ts`. Записаться можно заранее, а
  после закрытия — уже на завтра; свои прошедшие дни с местом и выигрышем
  лежат в кабинете, в разделе «Турниры».
- **Служба.** Пульт над чужими аккаунтами — поиск игрока, жетоны, смена
  имени, снятие рисунка, журнал действий — живёт отдельной страницей
  `…/dottony/admin.html`. Кто служащий, задаёт `ADMIN_TELEGRAM_IDS` на
  сервере; отдельного пароля нет, вход обычный, через свой аккаунт. Порядок
  — в [docs/DEPLOY.md](docs/DEPLOY.md#служба-пульт-над-чужими-аккаунтами).
- **Наладка.** Чтобы посмотреть состояния, до которых игрой идти часами
  (полный корпус, все оправы, свой шильдик, лига, пустой аккаунт),
  запустите сервер с `SERVICE_KEY=…` и откройте клиент адресом
  `?service=…` — в кабинете появится служебная полоса. На боевом сервере
  ключ не задавать: подробности и почему — в
  [docs/DEPLOY.md](docs/DEPLOY.md#наладка-прибор-со-снятой-крышкой).
- **База.** По умолчанию libSQL пишет в файл `doton.db` рядом с приложением;
  на бесплатных хостингах без постоянного диска он исчезает при
  перезапуске. Чтобы результаты жили, заведите бесплатную базу
  [Turso](https://turso.tech) и задайте `DATABASE_URL` (`libsql://…`) и
  `DATABASE_AUTH_TOKEN` — код и SQL те же.
### Telegram

Вход, приглашения и уведомления работают через одного бота:

1. У [@BotFather](https://t.me/BotFather): `/newbot` — забрать токен;
   `/newapp` — завести мини-приложение и указать адрес клиента на GitHub
   Pages. Короткое имя приложения из `/newapp` — это `TELEGRAM_APP_NAME`.
2. В дашборде Render у сервиса → **Environment**: `TELEGRAM_BOT_TOKEN`
   (обязательно) и `TELEGRAM_APP_NAME` (если мини-приложение названное;
   без него ссылки ведут в главное мини-приложение бота).
3. Больше ничего делать не нужно: вебхук сервер регистрирует сам по
   адресу из `RENDER_EXTERNAL_URL`, секрет вебхука выводится из
   `JWT_SECRET`. Проверить, доехал ли токен, можно по `/api/health` —
   там есть поля `telegram` и `bot`.

Локально вебхук не регистрируется: без `PUBLIC_URL` сервер не трогает
чужие настройки бота, поэтому запуск на ноутбуке не отнимает вебхук у
прода.

## Статус

Этап 4 из [плана](CONCEPT.md#9-этапы): кабинет, друзья, Telegram.

- **Соло:** по режиму на механику. **Цепочки** — три минуты на максимум
  потенциала, попыток сколько угодно, в таблицу идёт лучший заход. **Тап** —
  окна вместо часов: прибор звенит цветом на 18 секунд, надо снять 25 точек
  этого цвета одним касанием, три пустых окна кончают заход. Счёт обоих
  подтверждает сервер, переигрывая заход по журналу ходов; стоп-кадра нет —
  остановка часов была бы форой.
- **Дуэли:** матч на одинаковом поле — полторы минуты на цепочках, три на тапе, счёт соперника в реальном
  времени, подбор соперника и вызов друга по коду комнаты.
  Каждый ход проверяется сервером через то же ядро, что и у клиента: счёт
  клиента не принимается на веру, уход из матча засчитывается поражением.
- **Призраки:** если живой соперник не нашёлся за 10 секунд, игрок получает
  матч против записи чужой дуэли — на её же сиде, поэтому поле ровно то,
  которое проходил соперник. Запись всегда честно помечена («· запись»).
  Пока записей нет, соперника отыгрывает «Эталон» примерно в силу игрока.
- **Рейтинг:** Glicko-2 с калибровкой в пять матчей и лигами от «Ученика
  алхимика» до «Гордона Фримена». Считается только за открытый подбор: в комнате с
  другом результат легко нарисовать, а призрак не может проиграть.
- **Кабинет:** профиль, история матчей, реплеи партий. Аккаунт и способ
  входа разделены (`identities`), поэтому один игрок может входить и
  гостем, и через Telegram, и позже кошельком TON.
- **Жетоны:** валюта прибора. По одному за каждый доведённый до конца
  заход и за каждый матч, не чаще раза в 50 секунд. Тратятся на наклейки и
  оправу полосы; ничего, что влияет на игру, за них не продаётся.
- **Механики две, и они разделены до конца:** у цепочек и тапа свои меню,
  свои одиночные режимы, свои дуэли и свои рейтинги. Переключает их клавиша
  `⇄` на корпусе; общее число на двоих врало бы про обе.
- **Друзья:** код друга и добавление соперника прямо с экрана результата;
  в списке виден личный счёт между вами. Позвать друга можно сообщением
  в Telegram — бот пришлёт ему код комнаты.
- Впереди: асинхронный вызов друга призраком, привязка TON-кошелька,
  турниры.
