# Шрифты

Лежат в репозитории, а не тянутся с Google Fonts: внешний запрос при каждой
загрузке — лишняя точка отказа, а внутри Telegram ещё и лишняя задержка.

| Файл | Шрифт | Лицензия |
|---|---|---|
| `inter-*.woff2` | [Inter](https://github.com/rsms/inter) | SIL Open Font License 1.1 |
| `jetbrains-*.woff2` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |

Взяты вариативные версии, подмножества `latin` и `cyrillic` — тех же, что
раздаёт Google Fonts. Диапазоны символов прописаны в `@font-face` внутри
`index.html`, поэтому браузер качает только нужный файл.

Макет предлагал гротеск **Archivo**, но у него нет кириллицы — весь русский
текст всё равно рисовался бы системным шрифтом. Взят Inter: он с кириллицей и
так же нейтрален. Почти вся типографика прибора и без того моноширинная.
